### Cada Sección Explicada:

| Sección | Función |
|---------|---------|
| **Barra Superior** | Guardar, deshacer, rehacer, opciones generales |
| **Panel Izquierdo** | Herramientas para añadir elementos (texto, imagen, formas) |
| **Centro (Lienzo)** | Tu área de diseño - aquí crearás tu diseño |
| **Panel Derecho** | Propiedades del elemento seleccionado |
| **Panel Capas** | Lista de todos tus elementos |
| **Barra Zoom** | Ampliar/reducir la vista |

## 🎯 Cómo Empezar: Proyecto Paso a Paso

### Proyecto: Camiseta Personalizada con Nombre

#### PASO 1: Escribe el Nombre (Texto)

```
En el panel izquierdo:
1. Haz clic en el icono "Texto" o "Añadir Texto"

   [📝 TEXTO]
        ↓
2. Se abrirá un cuadro de entrada de texto

   ┌─────────────────────────┐
   │ Escribe tu nombre aquí: │
   │ [               ]       │
   └─────────────────────────┘

3. Escribe el nombre (ej: "JUAN")

4. Haz clic fuera o presiona Enter

Resultado:
┌─────────────────────────────┐
│                             │
│         JUAN                │  ← Tu nombre
│    (con cuadro alrededor)   │     aparece en
│         [esquinas]          │     el lienzo
│                             │
└─────────────────────────────┘
```

#### PASO 2: Ajusta el Tamaño del Texto

```
Ahora tienes el texto. Pero es muy pequeño.

Panel Derecho - Propiedades:
┌─────────────────────────────┐
│ TAMAÑO DE FUENTE:           │
│ [    18    ]  ← Cambiar esto│
│                             │
│ Aumenta a: 48 o más        │
│ [    48    ]                │
└─────────────────────────────┘

¿Cómo cambiarlo?

MÉTODO 1: Escribe el número
1. Haz clic en el campo de número
2. Borra el número anterior
3. Escribe 48 (o más grande)
4. Presiona Enter

MÉTODO 2: Usa las flechas
1. Encuentra las flechas ▲▼ cerca del número
2. Haz clic en ▲ para aumentar
3. Haz clic en ▼ para disminuir

Resultado visual:
Juan  ← Pequeño (18)
JUAN  ← Mediano (36)
J U A N  ← Grande (48)
```

#### PASO 3: Colorea el Texto

```
Ahora el texto es más grande. Pero es negro.

Panel Derecho - Color:
┌─────────────────────────────┐
│ COLOR:                      │
│ [████] ← Cuadrado de color  │
│                             │
│ Haz clic en el cuadrado     │
└─────────────────────────────┘

¿Qué sucede?

Se abre un "selector de colores":
┌─────────────────────────────┐
│       SELECTOR DE COLORES    │
│                             │
│   Haz clic en un color:     │
│   ██ Rojo      ██ Azul      │
│   ██ Verde     ██ Amarillo  │
│   ██ Negro     ██ Blanco    │
│                             │
│   O ESCRIBE CÓDIGO:         │
│   #FF0000 (rojo)            │
│   #0000FF (azul)            │
│   etc...                    │
└─────────────────────────────┘

Ejemplo: Selecciona Rojo

Antes:                Después:
JUAN (negro)    →    JUAN (rojo)
```

#### PASO 4: Posiciona el Texto (Centrado)

```
Tu texto está ahora grande y rojo.
Pero está en la esquina superior izquierda.

Panel Derecho - Posición:
┌─────────────────────────────┐
│ POSICIÓN:                   │
│ X: [ 10 ]  (distancia izq)  │
│ Y: [ 20 ]  (distancia arriba)
│                             │
│ O USA BOTONES DE ALINEACIÓN:│
│ [Izq] [Centro] [Derecha]    │
│ [Arriba] [Centro] [Abajo]   │
└─────────────────────────────┘

OPCIÓN 1: Arrastrar visualmente
1. Haz clic en el texto (JUAN)
2. Arrastra hacia el centro del lienzo
3. Suelta cuando esté donde quieras

Antes:                Después (Centrado):
JUAN                       JUAN
(arriba izquierda)        (en el centro)


OPCIÓN 2: Usar botones
1. Selecciona el texto (JUAN)
2. En el panel derecho, busca botones de alineación
3. Haz clic en "Centrar"
4. El texto se va al centro automáticamente
```

#### PASO 5: ¡Resultado Final!

```
Tu primer diseño está listo:

┌─────────────────────────┐
│                         │
│                         │
│        JUAN ✓          │  ← Grande, rojo, centrado
│                         │
│                         │
│                         │
└─────────────────────────┘

✓ Texto grande (48 pts)
✓ Color rojo
✓ Centrado en la camiseta
✓ Guardado automáticamente

¡Ahora puedes proceder al checkout!
```

## 🎯 Operaciones Comunes - Visual

### Operación 1: Duplicar un Elemento

```
Quieres dos logos iguales (uno a cada lado)

PASO 1: Selecciona el logo
┌──────────────────────────┐
│   ┌────────┐             │
│   │[LOGO]  │ ← Selecciona│
│   └────────┘             │
│                          │
└──────────────────────────┘

PASO 2: Copia (Ctrl+C)
┌──────────────────────────┐
│   ┌────────┐             │
│   │[LOGO]  │ Copiado     │
│   └────────┘             │
│                          │
└──────────────────────────┘

PASO 3: Pega (Ctrl+V)
┌──────────────────────────┐
│   ┌────────┐             │
│   │[LOGO]  │ Original    │
│   └────────┘             │
│   ┌────────┐ ← Copia     │
│   │[LOGO]  │ (encima)    │
│   └────────┘             │
└──────────────────────────┘

PASO 4: Arrastra la copia al otro lado
┌──────────────────────────┐
│ ┌────────┐   ┌────────┐  │
│ │[LOGO]  │   │[LOGO]  │  │
│ └────────┘   └────────┘  │
│                          │
└──────────────────────────┘

¡Resultado: Dos logos simétricos!
```

### Operación 2: Cambiar el Orden (Capas)

```
Tienes una imagen atrás de un texto
pero quieres que el texto esté atrás.

Panel de CAPAS (izquierda):
┌──────────────────────┐
│ CAPAS:               │
│ ☑ Texto ← Delante    │
│ ☑ Imagen ← Atrás    │
└──────────────────────┘

Visual:

Actual (Texto delante):    Deseado (Imagen delante):
Text Image                 Image Text
████████                   ╔════════════╗
┌─────────┐                │  ████████  │
│ Image   │                │ ┌────────┐ │
│ Texto   │                │ │ Texto  │ │
│ ☑════════│                │ └────────┘ │
└─────────┘                ╚════════════╝

¿Cómo cambiar?

En el panel de capas:
1. Arrastra "Texto" debajo de "Imagen"
   O
2. Selecciona "Texto"
3. Haz clic en botón "Atrás" (▼)

Resultado: Imagen está delante, texto atrás
```

## ❌ Errores Comunes y Cómo Evitarlos

### Error 1: Texto Cortado

```
❌ PROBLEMA:
┌──────────────────────────┐
│ MI NO│ ← Se ve cortado
│      │
└──────────────────────────┘

¿Por qué?
El texto está fuera del área segura
(línea roja interior)

✅ SOLUCIÓN:
1. Selecciona el texto
2. Panel Derecho → POSICIÓN
3. Cambia X o Y para mover
4. Asegúrate de estar dentro de:
   ┌──────────────────────────┐
   │  ┌────────────────────┐  │
   │  │ MI NOMBRE ✓        │  │
   │  └────────────────────┘  │
   └──────────────────────────┘
```

### Error 2: Imagen Borrosa

```
❌ PROBLEMA:
La imagen se ve pixelada/borrosa

┌──────────────────────┐
│ ░░░░░░░░░░░░░░░░    │
│ ░░░░░░░░░░░░░░░░    │
│ ░░░░ [FOTO] ░░░░    │
│ ░░░░░░░░░░░░░░░░    │
└──────────────────────┘

¿Por qué?
• Imagen muy pequeña (baja resolución)
• Imagen hecha muy grande en el editor

✅ SOLUCIÓN:
1. Usa una imagen más grande
   (mínimo 300x300 píxeles)
2. No agrades demasiado en el editor
   (mejor pequeño que grande)
3. Verifica: ¿imagen original es buena calidad?
```

### Error 3: Colores No Combinan

```
❌ PROBLEMA:
Texto rojo en fondo rosado = no se ve

┌──────────────────────┐
│ Rojo en Rosado       │
│ (no se ve claro)     │
└──────────────────────┘

✅ SOLUCIÓN:
Usa CONTRASTE (colores opuestos):

BUENAS COMBINACIONES:
• Texto negro en fondo blanco   ✓
• Texto blanco en fondo negro   ✓
• Texto rojo en fondo blanco    ✓
• Texto azul en fondo amarillo  ✓

MALAS COMBINACIONES:
• Texto rojo en fondo rosado    ✗
• Texto gris en fondo gris      ✗
• Texto azul en fondo azul      ✗
• Texto rojo en fondo naranja   ✗
```

### Error 4: Elemento Desapareció

```
❌ PROBLEMA:
Tenía un elemento pero ya no lo veo

✅ SOLUCIONES:

1. ¿Está fuera del lienzo?
   Panel Derecho → POSICIÓN
   Cambia X e Y a valores normales
   Ej: X: 50, Y: 50

2. ¿Está atrás de otro elemento?
   Panel CAPAS (izquierda)
   Arrastra el elemento hacia adelante

3. ¿Es completamente transparente?
   Panel Derecho → OPACIDAD
   Cambia a 100%

4. ¿Lo eliminaste accidentalmente?
   Ctrl+Z (deshacer) varias veces
```

## 💡 Consejos de Diseño Profesional

### Consejo 1: Usa Espacio en Blanco

```
❌ Lleno (se ve desordenado):        ✅ Con espacio (se ve limpio):
Text1 Text2 Text3 Text4              Texto Principal
Image1 Image2 Image3
Shape1 Shape2 Shape3                 [Imagen]

Muchos elementos                     Menos, mejor distribuido
Sin espacio                          Con espacio alrededor
```

### Consejo 2: Alinea TODO

```
❌ Sin alineación (caótico):          ✅ Alineado (profesional):
  Text                               Text
    Image                            Image
  Shape                              Shape
    Logo                             Logo

No en línea                          En línea perfecta
Parece accidental                    Parece intencional
```

### Consejo 3: Elige 2-3 Colores Máximo

```
❌ Muchos colores (confuso):          ✅ Pocos colores (armónico):
🔴 Rojo  🔵 Azul  🟢 Verde           🔴 Rojo
🟡 Amarillo  🟣 Morado               🟠 Naranja
🟤 Marrón  ⚫ Negro                   ⚫ Negro

6+ colores                           2-3 colores
Demasiado visualmente               Cohesivo y limpio
```

### Consejo 4: Jerarquía Visual

```
Haz que lo IMPORTANTE sea el más grande

PRINCIPAL (Grande):
┌─────────────────┐
│ MI EMPRESA      │  ← Título principal
└─────────────────┘

SECUNDARIO (Mediano):
[Logo]             ← Logo mediamente grande

PEQUEÑO:
www.miempresa.com  ← Detalles pequeños
```

## 🎮 Atajos Rápidos (Trucos)

```
ATAJOS IMPORTANTES:

Ctrl+Z              Deshacer última acción
Ctrl+Y              Rehacer acción
Ctrl+C              Copiar elemento
Ctrl+V              Pegar elemento
Ctrl+A              Seleccionar TODO
Delete              Eliminar seleccionado

Ctrl++              Acercar (zoom in)
Ctrl+-              Alejar (zoom out)
Ctrl+0              Ver todo en pantalla

Espacio + Arrastra  Mover el lienzo (panorama)

EJEMPLO:
Quieres hacer varias copias de un logo:
1. Selecciona logo
2. Ctrl+C (copiar)
3. Ctrl+V (pegar) - aparece copia
4. Arrastra a otro lugar
5. Ctrl+V (pegar otra) - aparece otra copia
6. Arrastra a otro lugar
... repite según necesites
```

## ✅ Checklist Antes de Comprar

```
Tu diseño está listo cuando:

□ El texto es fácil de leer
  (Grande, color contraste)

□ La imagen es de buena calidad
  (No borrosa, no muy pequeña)

□ Todo está en el área segura
  (Dentro de la línea roja)

□ El diseño está balanceado
  (No todo en un lado)

□ Los colores funcionan juntos
  (Combinan bien, buen contraste)

□ No hay errores de ortografía
  (Revisa el texto cuidadosamente)

□ Se ve profesional
  (Te gustaría verlo en el producto)

□ Está guardado
  (Nube verde sin problemas)

□ Has revisado ambos lados
  (Si el producto tiene dos caras)

Si TODO está ✓, ¡compra con confianza!
```

## 🎬 Flujo Completo de Compra

```
ANTES DE DISEÑAR:
├─ Abre la página del producto
├─ Haz clic en "Personalizar"
└─ Espera a que cargue el editor

MIENTRAS DISEÑAS:
├─ Añade tus elementos (texto, imagen, formas)
├─ Colores y estilo
├─ Ajusta posiciones y tamaños
├─ Revisa que se vea bien

DESPUÉS DE DISEÑAR:

├─ Procede a Checkout
└─ ¡Compra completada!

ENTREGAS Y RECEPCIÓN:
├─ Tu producto se fabrica con tu diseño
├─ Recibes un código de seguimiento
├─ El producto llega a tu casa
└─ ¡Disfruta tu creación! 🎉
```

## 🚨 Problemas Finales y Soluciones Rápidas

```
PROBLEMA: No puedo editar el texto
SOLUCIÓN: Haz DOBLE CLIC en el texto
         (una vez lo selecciona, dos veces lo edita)

PROBLEMA: El elemento desapareció
SOLUCIÓN: Ctrl+Z (deshacer varias veces)
         O busca en panel de CAPAS

PROBLEMA: La página es muy lenta
SOLUCIÓN: Reduce el zoom
         O cierra otras pestañas
         O recarga la página (F5)

PROBLEMA: No se guarda
SOLUCIÓN: Verifica internet está conectado
         O recarga la página (F5)
         O contacta soporte

PROBLEMA: Colores se ven distintos
SOLUCIÓN: Es normal (pantalla vs producto)
         Usa colores básicos y luminosos
         Evita grises muy claros u oscuros

PROBLEMA: Quiero empezar de nuevo
SOLUCIÓN: Panel Izquierdo → Menú → Limpiar
         O recarga la página sin guardar
         Nota: Si ya guardaste, necesitarás un reset
```
