## ¿Qué es este editor?

### Explicación Simple

Este es un **editor de diseño visual en línea**. Es como tener un programa de diseño profesional (como Photoshop) directamente en tu navegador, pero mucho más simple y fácil de usar.

### ¿Para qué sirve?

Imagina que compras una camiseta. Este editor te permite:
- ✏️ Escribir tu nombre o un mensaje
- 🖼️ Añadir fotos e imágenes
- 🎨 Cambiar colores
- ✨ Posicionar elementos exactamente donde quieras
- 👁️ Ver cómo se vería antes de comprar

### ¿Qué puedo hacer?

Con este editor puedes personalizar productos como:
- 👕 Camisetas
- ☕ Tazas
- 📱 Fundas de teléfono
- 🎒 Mochilas
- 🧥 Chaquetas
- Y mucho más

## Primeros pasos

### Paso 1: Acceder al editor

```
1. En la página del producto → Haz clic en "Personalizar" o "Diseña el tuyo"
2. Se abrirá el editor (puede tomar 3-5 segundos)
3. Verás el área blanca en el centro - ese es tu lienzo
```

Cuando abres el editor por primera vez, verás:
- Una página en blanco (el "lienzo")
- Un panel de herramientas a la izquierda
- Opciones de propiedades a la derecha
- Barras de menú arriba y abajo

```

├─────────────────────────────────────────┤
│ │                                       │
```

## Entender la pantalla

### El Lienzo (Área Central Blanca)

**¿Qué es?**
El lienzo es donde crearás tu diseño. Es como una hoja de papel en blanco. Todo lo que hagas aquí aparecerá en el producto final.

**Partes importantes:**

```
     REGLA HORIZONTAL (arriba)
            ↓
        ╔════════════╗
        ║            ║
    ╚═══╣  LIENZO    ╣═══╝
    ║   ║            ║   ║
    ║   ║            ║   ║
    ║   ║            ║   ║
    ║   ╚════════════╝   ║
    ║
REGLA        ÁREA DE DISEÑO
VERTICAL         (lo que se verá
(izquierda)    en el producto)
```

**Las líneas del lienzo:**
- 📏 **Línea azul/morada (exterior):** El área de sangrado. Se corta en la producción
- 📏 **Línea roja (interior):** El área segura. Aquí es donde debería estar todo lo importante

**¿Por qué hay dos líneas?**
La línea exterior es donde se corta el producto (por ejemplo, dónde se corta la camiseta). Si pones algo exactamente en el borde, podría cortarse. Por eso existe la línea segura - todo lo importante debe estar dentro de ella.

## Herramientas de la Izquierda

### 📝 HERRAMIENTA: AÑADIR TEXTO

**¿Para qué sirve?**
Te permite escribir texto en el lienzo: tu nombre, un mensaje, una frase, etc.

**Cómo usarla:**

```
PASO 1: Haz clic en "TEXTO"
   ↓
PASO 2: Haz clic en el lienzo donde quieres el texto
   ↓
PASO 3: Se abrirá una caja de texto - escribe lo que quieras
   ↓
PASO 4: Presiona Enter o haz clic fuera para terminar
```

**Resultado:**
Tu texto aparecerá en el lienzo. Verás un cuadro alrededor (significa que está seleccionado).

**Ejemplo:**
```
Si escribes "Juan" en el lienzo:

    ┌─────────────────┐
    │                 │
    │     Juan        │  ← Tu nombre aparece
    │  [esquinas]     │     aquí
    │                 │
    └─────────────────┘
```

### 📷 HERRAMIENTA: AÑADIR IMAGEN

**¿Para qué sirve?**
Te permite subir una foto o imagen desde tu computadora.

**Cómo usarla:**

```
PASO 1: Haz clic en "IMAGEN"
   ↓
PASO 2: Verás opciones para:
   • Subir desde tu PC
   • Seleccionar de una galería predefinida
   ↓
PASO 3: Selecciona o sube tu imagen
   ↓
PASO 4: Haz clic en el lienzo para colocarla
```

**Resultado:**
Tu imagen aparecerá en el lienzo.

**Importante:**
- Usa imágenes de buena calidad (mínimo 300x300 píxeles)
- Formatos: JPG, PNG
- No hagas la imagen demasiado pequeña - se vería borrosa
- Si la imagen está inclinada, puedes girarla (ver sección de herramientas)

### 🔴 HERRAMIENTA: FORMAS

**¿Para qué sirve?**
Te permite añadir formas como rectángulos, círculos, triángulos, etc.

**¿Cuándo usar formas?**
- Para crear fondos detrás del texto
- Para decoración
- Para enmarcar una imagen
- Para crear diseños geométricos

**Cómo usarla:**

```
PASO 1: Haz clic en "FORMAS"
   ↓
PASO 2: Elige el tipo de forma:
   • Círculo
   • Rectángulo
   • Triángulo
   • Línea
   ↓
PASO 3: Haz clic y arrastra en el lienzo
   ↓
PASO 4: Se creará la forma
```

**Ejemplo:**
```
Si creas un rectángulo:

    ┌─────────────────┐
    │ ┌─────────────┐ │
    │ │ RECTÁNGULO  │ │  ← La forma aparece
    │ └─────────────┘ │     en el lienzo
    └─────────────────┘
```

## Panel de Propiedades (Derecha)

Cuando seleccionas algo en el lienzo, aparece un panel a la derecha con opciones. Aquí está lo que puedes cambiar:

### 🎨 COLOR

**¿Para qué sirve?**
Cambiar el color de un elemento (texto, forma, etc.).

**Cómo usarla:**

```
PASO 1: Selecciona el elemento que quieres cambiar
        (haz clic en él en el lienzo)
   ↓
PASO 2: En el panel derecho, busca "Color"
   ↓
PASO 3: Haz clic en el cuadrado de color
   ↓
PASO 4: Se abrirá un selector de colores
   ↓
PASO 5: Elige el color que quieras
   ↓
PASO 6: El elemento cambia de color inmediatamente
```

**Tipos de color:**
- **Colores sólidos:** Un color uniforme (rojo, azul, verde, etc.)
- **Gradiente:** Un degradado entre dos colores
- **Personalizados:** Escribe el código de color si conoces uno

### 📏 TAMAÑO

**¿Para qué sirve?**
Cambiar el ancho y alto de un elemento.

**Cómo usarla:**

```
En el panel derecho verás:
• Ancho: (número) px
• Alto: (número) px

Puedes:
1. Escribir un número diferente
2. Presionar Enter
3. El elemento cambiará de tamaño
```

**Consejo:**
Si quieres que la imagen se mantenga proporcionada (no se deforme), busca un botón con un candadito 🔒 que une ancho y alto. Déjalo activado.

### 📍 POSICIÓN

**¿Para qué sirve?**
Mover un elemento a una posición exacta en el lienzo.

**Cómo usarla:**

**Método 1: Arrastrando**
```
1. Haz clic en el elemento
2. Arrastra con el ratón
3. Suelta cuando esté donde quieres
```

**Método 2: Usando números**
```
En el panel derecho verás:
• Posición X: (número) - es la distancia desde la izquierda
• Posición Y: (número) - es la distancia desde arriba

Puedes escribir números exactos para colocar
el elemento en una posición precisa
```

**Ejemplo visual:**
```
Si la posición es X:50, Y:50:

    ┌─────────────────┐
    │ 0px             │
    │                 │
    │   50px↓         │
    │   ┌──┐          │
    │   │██│ 50px→   │
    │   └──┘          │
    └─────────────────┘
```

### 🔄 ROTACIÓN

**¿Para qué sirve?**
Girar un elemento (texto, imagen, forma) en cualquier ángulo.

**¿Cuándo usarla?**
- Para inclinar un texto
- Para girar una imagen
- Para crear efectos de diseño

**Cómo usarla:**

**Método 1: Visualmente**
```
1. Selecciona el elemento
2. En los controles visuales, verás una esquina
   superior con un pequeño círculo
3. Haz clic y arrastra ese círculo
4. El elemento girará según muevas el ratón
```

**Método 2: Números**
```
En el panel derecho:
• Rotación: (número) grados

Escribe:
• 0° = Normal (sin girar)
• 45° = Girado 45 grados
• 90° = Girado 90 grados (acostado)
• 180° = De cabeza
```

**Ejemplo:**
```
Sin rotación:        Con 45° rotación:
Juan                  J
                     u
                      a
                       n
```

### 💧 OPACIDAD / TRANSPARENCIA

**¿Para qué sirve?**
Hacer que un elemento sea más o menos transparente (invisible).

**¿Cuándo usarla?**
- Para crear fondos sutiles
- Para hacer que el texto sea más legible
- Para efectos creativos

**Cómo usarla:**

```
En el panel derecho:
• Opacidad: 0% a 100%

Donde:
• 100% = Completamente sólido (opaco)
• 50% = Medio transparente
• 0% = Completamente invisible
```

**Ejemplo visual:**
```
100% Opacidad:    50% Opacidad:    0% Opacidad:
████████          ░░░░░░░░         (invisible)
████████          ░░░░░░░░
████████          ░░░░░░░░
```

### 🔤 FUENTE (para texto)

**¿Para qué sirve?**
Cambiar el tipo de letra del texto.

**Cómo usarla:**

```
PASO 1: Selecciona el texto (haz clic en él)
   ↓
PASO 2: En el panel derecho, busca "Fuente"
   ↓
PASO 3: Haz clic en el menú desplegable
   ↓
PASO 4: Elige la fuente que quieras
   ↓
PASO 5: El texto cambia inmediatamente
```

**Tipos de fuentes:**
- **Serif:** Con adornos (clásico, profesional)
- **Sans-serif:** Limpio y moderno
- **Decorativa:** Especial y artística

### 📐 TAMAÑO DE TEXTO

**¿Para qué sirve?**
Hacer el texto más grande o más pequeño.

**¿Cuándo cambiar el tamaño?**
- Títulos: Grande (40-60)
- Subtítulos: Mediano (24-36)
- Cuerpo: Pequeño (12-18)

**Cómo usarla:**

```
En el panel derecho:
• Tamaño de fuente: (número)

Números usuales:
• 12 = Muy pequeño (difícil de leer)
• 24 = Mediano (bueno para la mayoría)
• 48 = Grande (para títulos)
• 72 = Muy grande (para énfasis)
```

## Operaciones Comunes

### ✂️ COPIAR Y PEGAR (Duplicar)

**¿Para qué sirve?**
Hacer una copia de un elemento que ya existe.

**¿Cuándo usarla?**
- Cuando quieres dos elementos iguales
- Para no tener que crear algo nuevamente

**Cómo hacerlo:**

```
MÉTODO 1: Atajo de teclado
1. Selecciona el elemento
2. Presiona Ctrl+C (o Cmd+C en Mac)
3. Presiona Ctrl+V (o Cmd+V en Mac)
4. Se crea una copia encima del original

MÉTODO 2: Menú contextual
1. Haz clic derecho en el elemento
2. Selecciona "Duplicar"
3. Se crea una copia
4. Arrastra la copia a donde quieras
```

### 🗑️ ELIMINAR

**¿Para qué sirve?**
Borrar un elemento que no quieres.

**¿Cuándo usarla?**
- Cometiste un error
- Ya no necesitas ese elemento
- Quieres empezar de nuevo

**Cómo hacerlo:**

```
PASO 1: Selecciona el elemento (haz clic en él)
   ↓
PASO 2: Presiona la tecla Delete o Suprimir
   ↓
PASO 3: ¡El elemento desaparece!
```

**⚠️ Importante:** Esto es irreversible. Si lo necesitas nuevamente, tendrás que recrearlo.

### 🔄 DESHACER Y REHACER

**¿Para qué sirve?**
Deshacer un cambio que hiciste por error y luego rehacerlo.

**Cómo usarla:**

```
DESHACER (volver atrás):
• Atajo: Ctrl+Z (o Cmd+Z en Mac)
• O: Menú → Editar → Deshacer

REHACER (volver adelante):
• Atajo: Ctrl+Y (o Cmd+Shift+Z en Mac)
• O: Menú → Editar → Rehacer
```

**Ejemplo:**
```
Paso 1: Escribes "Juan"
Paso 2: Cambias a rojo
Paso 3: Presionas Ctrl+Z → vuelve a ser negro
Paso 4: Presionas Ctrl+Y → vuelve a ser rojo
```

### 🎯 ALINEAR Y CENTRAR

**¿Para qué sirve?**
Alinear elementos para que se vean ordenados y profesionales.

**Tipos de alineación:**

```
ALINEAR A LA IZQUIERDA:
█         └─ Todo a la izquierda
█
█

CENTRAR HORIZONTALMENTE:
  █      └─ Todo en el centro
  █
  █

CENTRAR EN LA PÁGINA:
Uno o varios elementos exactamente
en el medio de tu área de diseño
```

**Cómo usarla:**

```
1. Selecciona un elemento (o varios)
2. En la barra de herramientas busca iconos de alineación
3. Haz clic en el tipo de alineación que quieras
4. Los elementos se alinean automáticamente
```

## Consejos y Trucos

### 💡 Consejo 1: Usa Capas para Organizar

Si tu diseño tiene muchos elementos, tienes un panel de "Capas" a la izquierda.

```
¿Qué son capas?

Imagina que tu diseño es como un sándwich:
• Pan (capa inferior) = Fondo
• Lechuga (capa 2) = Imagen
• Queso (capa 3) = Texto
• Pan (capa superior) = Decoración

Las capas superiores cubren a las inferiores.
```

**Cómo usar capas:**
```
1. Abre el panel de "Capas" (izquierda)
2. Verás todos tus elementos listados
3. Puedes:
   • Haz clic en una capa para seleccionarla
   • Arrastra para reordenar (cambiar qué está encima)
   • Haz clic en el ojo para mostrar/ocultar
   • Haz clic en el candado para bloquear/desbloquear
```

### 💡 Consejo 2: Reglas Visuales para Buen Diseño

**Espacio en blanco:**
No llenes todo el lienzo. Deja espacio vacío. Se verá mejor.

```
❌ Malo:                ✅ Bueno:
TextoFoto             Texto
ImagenMás
Más cosas                 Foto
Aún más
```

**Alineación:**
Alinea los elementos para que se vean ordenados.

```
❌ Malo:               ✅ Bueno:
   Texto              Texto
 Foto            Foto
    Otro            Otro
```

**Contraste de color:**
Asegúrate de que el texto sea legible sobre el fondo.

```
❌ Malo:              ✅ Bueno:
Texto rojo          Texto negro
en fondo rosado     en fondo blanco
(no se ve)          (se ve claro)
```

### 💡 Consejo 3: Múltiples Páginas

Si el producto tiene dos lados (ej: frente y espalda), verás botones para cambiar de página.

```
Ejemplo: Camiseta

   PÁGINA 1          PÁGINA 2
   (Frente)         (Espalda)

   ┌────────┐      ┌────────┐
   │FRENTE  │  ↔   │ESPALDA │
   │        │      │        │
   └────────┘      └────────┘

Diseña cada lado por separado
```

**Cómo cambiar de página:**
- Botones de flechas en la barra superior
- O haz clic en los números (1/2, 2/2, etc.)

### 💡 Consejo 4: Usar Zoom

Puedes hacer zoom (acercar y alejar) para ver mejor.

```
ACERCAR (zoom in):
• Rueda del ratón hacia arriba, O
• Presiona Ctrl + Más (+)

ALEJAR (zoom out):
• Rueda del ratón hacia abajo, O
• Presiona Ctrl + Menos (-)

AJUSTAR A LA PANTALLA:
• Tecla "0" o menú View
```

## Solucionar Problemas

### ❓ Mi texto se ve muy pequeño / no se lee

**Solución:**
1. Selecciona el texto (haz clic en él)
2. Aumenta el "Tamaño de fuente" en el panel derecho
3. Recomendación: mínimo 18 para que se lea bien

### ❓ Mi imagen se ve borrosa

**Posibles causas:**
- La imagen original es de baja calidad
- Has hecho la imagen demasiado grande en el lienzo

**Soluciones:**
1. Usa una imagen de mejor calidad (más píxeles)
2. No hagas la imagen más grande de lo necesario
3. El tamaño mínimo debería ser 300x300 píxeles

### ❓ El elemento desapareció

**Probables razones:**
- Lo moviste fuera del área visible
- Está detrás de otro elemento
- Lo hiciste totalmente transparente (opacidad 0%)

**Soluciones:**
1. Presiona Ctrl+Z para deshacer
2. Busca en el panel de capas y haz clic en el elemento
3. Ajusta la opacidad a 100%

### ❓ Los cambios no se guardan

**Solución:**
1. Verifica tu conexión a internet (necesita estar conectado)
2. Mira la nube de sincronización en la esquina superior
   - Si dice "Guardando..." espera a que termine
   - Si tiene una X roja, hay problema - recarga la página
3. Intenta hacer clic en el botón "Guardar" (si lo hay)

### ❓ No puedo editar el texto

**Solución:**
1. Asegúrate de que el texto está seleccionado
2. Haz doble clic en el texto para entrar en modo edición
3. Deberías ver un cursor parpadeante
4. Ahora puedes escribir o editar

### ❓ Mi diseño se ve diferente en el producto final

**Esto es normal porque:**
- La pantalla del navegador es diferente al producto físico
- Los colores pueden variar ligeramente
- El material del producto afecta cómo se ve

**Para minimizar diferencias:**
1. Usa colores básicos (evita colores muy claros o oscuros)
2. Usa fuentes comunes (Arial, Helvetica, etc.)
3. Prueba con la vista previa si está disponible

### ❓ Presioné algo por accidente y no sé qué pasó

**Solución:**
Presiona Ctrl+Z (o Cmd+Z) una o varias veces para deshacer acciones.

```
Si presionas Ctrl+Z muchas veces, volverás
a un estado anterior de tu diseño.

Luego puedes presionar Ctrl+Y para rehacer
si no era lo que querías deshacer.
```

## Preguntas Frecuentes

### P: ¿Puedo importar un diseño que hice en otro programa?

**R:** Sí, pero debes convertirlo a imagen (JPG o PNG) e importarlo como imagen. No puedes importar archivos de Photoshop o Illustrator directamente.

### P: ¿Cuál es el tamaño máximo de archivo para una imagen?

**R:** Generalmente hasta 10 MB, pero se recomienda menos de 5 MB para mejor rendimiento.

### P: ¿Puedo usar fuentes personalizadas?

**R:** Dependiendo de la tienda, hay un conjunto de fuentes disponibles. Si necesitas una fuente específica, contacta con el administrador.

### P: ¿Qué pasa si no guardo mi diseño?

**R:** No necesitas presionar un botón guardar. El sistema guarda automáticamente cada cambio. Pero asegúrate de que la sincronización haya terminado antes de cerrar el navegador.

### P: ¿Puedo descargar mi diseño como imagen?

**R:** Sí, busca un botón "Descargar" en el menú. Generalmente oferece opciones como PNG, PDF, etc.

### P: ¿Puedo trabajar en el diseño en múltiples dispositivos?

**R:** Sí, tus cambios se guardan en línea. Puedes continuar desde otro dispositivo. Pero evita tener la página abierta en múltiples navegadores a la vez.

### P: ¿Hay un límite de cuántos elementos puedo añadir?

**R:** Técnicamente no, pero demasiados elementos pueden hacer el diseño lento. Recomendamos no más de 30-50 elementos por página.

### P: ¿Puedo cambiar el tamaño del área de diseño?

**R:** No, el tamaño está determinado por el producto. No puedes cambiarlo, pero puedes ver las dimensiones exactas en la información del producto.

### P: ¿Qué hago si algo no funciona correctamente?

**R:** Intenta:
1. Recargar la página (F5)
2. Limpiar el caché del navegador
3. Usar otro navegador (Chrome, Firefox, Safari)
4. Contactar con soporte si el problema persiste

### P: ¿Puedo obtener ayuda mientras diseño?

**R:** Sí, busca:
- Un botón de "?" o "Help" en la interfaz
- Un chat de soporte (si está disponible)
- Preguntas frecuentes en esta misma página

### P: ¿El diseño tiene que caber completamente en el área segura?

**R:** Lo importante debe estar en el área segura (línea roja interior). Las cosas fuera podría cortarse en la producción.

```
┌─────────────────────┐ ← Línea azul (sangrado)
│  ┌───────────────┐  │
│  │ ÁREA SEGURA   │  │ ← Línea roja (segura)
│  │               │  │
│  │ Pon lo        │  │
│  │ importante    │  │
│  │ AQUÍ          │  │
│  └───────────────┘  │
└─────────────────────┘
```

## Flujo Típico de Diseño

Aquí está el proceso normal para diseñar algo:

```
PASO 1: PLANIFICA
├─ ¿Qué quiero comunicar?
├─ ¿Qué mensaje necesita el texto?
├─ ¿Qué imagen debo usar?
└─ ¿Qué colores funcionan bien juntos?

PASO 2: AÑADE ELEMENTOS BÁSICOS
├─ Escribe el texto principal
├─ Añade una imagen (si la tienes)
├─ Añade formas para decoración

PASO 3: POSICIONA Y DISTRIBUYE
├─ Alinea los elementos
├─ Deja espacio en blanco
├─ Asegúrate de que esté balanceado

PASO 4: AÑADE COLORES Y ESTILO
├─ Cambia colores para que se vea bien
├─ Ajusta transparencias
├─ Verifica el contraste de texto

PASO 5: REVISA Y PERFECCIONA
├─ Verifica que todo sea legible
├─ Comprueba que esté dentro del área segura
├─ Zoom out para ver el resultado final

PASO 6: GUARDA Y PROCEDE AL CHECKOUT
└─ El sistema guarda automáticamente
└─ Procede a pagar
```

## Ejemplos de Diseños Comunes

### Ejemplo 1: Camiseta con Nombre

```
Objetivo: Una camiseta con el nombre grande en el frente

Pasos:
1. Añade TEXTO con el nombre
2. Aumenta el tamaño (48-72 pts)
3. Elige un color que contraste con la camiseta
4. Centra el texto
5. Opcional: Añade una decoración (forma) debajo

Resultado:
┌─────────────────┐
│                 │
│    JUAN         │
│   ═════════     │
│                 │
│                 │
└─────────────────┘
```

### Ejemplo 2: Taza con Foto y Nombre

```
Objetivo: Una taza con foto y nombre

Pasos:
1. Añade una IMAGEN (foto de 300x300 px mínimo)
2. Posiciona la foto en el centro
3. Añade TEXTO con el nombre encima o debajo
4. Elige un color para el texto que contraste
5. Centra ambos elementos

Resultado:
┌─────────────────┐
│    JUAN         │
│  ┌─────────┐    │
│  │ [FOTO]  │    │
│  └─────────┘    │
│                 │
└─────────────────┘
```

### Ejemplo 3: Mochila con Logotipo

```
Objetivo: Una mochila con logotipo

Pasos:
1. Sube un LOGOTIPO o IMAGEN
2. Haz que sea del tamaño apropiado (150x150 px aprox)
3. Posiciona en un lado (izquierda/centro)
4. Opcional: Añade TEXTO con el nombre de la marca
5. Usa colores que combinen con la mochila

Resultado:
┌─────────────────┐
│  [LOGO]         │
│                 │
│  MI MARCA       │
│                 │
│                 │
└─────────────────┘
```

## Checklist Final Antes de Comprar

```
Antes de pagar, asegúrate de:

□ Todo el texto es legible
□ El tamaño de la fuente es suficientemente grande
□ Los elementos importantes están en el área segura
□ No hay elementos cortados en los bordes
□ Los colores se ven bien juntos
□ El contraste de texto/fondo es bueno
□ El diseño está balanceado (no todo a un lado)
□ No hay errores de ortografía
□ La imagen es de buena calidad (no borrosa)
□ Todo está donde debería estar
□ El diseño se ve profesional
□ Has guardado todos los cambios (nube verde)

Si todo esto está bien, ¡estás listo para comprar!
```

## Glosario de Términos

**Lienzo:** El área donde diseñas (la página en blanco)

**Capa:** Cada elemento o grupo de elementos en el diseño

**Opacidad:** Qué tan transparente es algo (0% = invisible, 100% = sólido)

**Sangrado:** El área que se corta en la producción

**Área segura:** El área donde definitivamente no se cortará nada

**Zoom:** Acercar (zoom in) o alejar (zoom out) la vista

**Alineación:** Posicionar elementos en línea (izquierda, centro, derecha)

**Píxeles:** Unidad de medida para imágenes digitales

**DPI:** Puntos por pulgada - refleja la calidad de la imagen

**Degradado:** Transición suave entre dos o más colores

**Fuente:** El tipo de letra (Arial, Helvetica, etc.)
